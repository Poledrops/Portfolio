# Murat Akpınar — Portfolio

Tek sayfalık, sade ve iki dilli (TR / EN) kişisel portfolio sitesi. React + Vite.

```bash
npm install
npm run dev      # geliştirme sunucusu
npm run build    # dist/ klasörüne üretim çıktısı
```

Yayın: `main` dalına push edilince GitHub Actions ile GitHub Pages'e deploy edilir
(Repo → Settings → Pages → Source: **GitHub Actions**).
